# 2-minute demo (record screen + sound; max 2 minutes -> demo.mp4)
1. (0:00) Run `python voice_chat.py`. Say: "My order hasn't arrived. Can I cancel it?" -> agent introduces itself, asks for order ID.
2. (0:25) Say the order ID, then the last 4 digits of the phone (use a sample order from the practice conversations).
3. (0:50) Ask the cancellation question; agent explains the shipped-order policy. Follow up: "How long will the refund take?" (shows memory).
4. (1:20) Ask something not in the documents -> "I don't have that information" + offer of a human. OR demand compensation -> polite refusal / handover.
5. (1:45) Show `outputs/results.csv` with the chunks used.
Tip: record your own voice only.
